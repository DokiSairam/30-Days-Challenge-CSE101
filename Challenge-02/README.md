# Challenge 02 – Journey Fuel Estimator

## Problem Description

A student wants to estimate the fuel expense for an upcoming journey. The program should accept the travelling distance, the vehicle's fuel efficiency in kilometres per litre, and the price of one litre of fuel. Using these values, determine how many litres of fuel will be needed and calculate the overall fuel expenditure.

## Purpose

The purpose of this program is to understand how input values can be stored in variables and used with arithmetic operations to solve a real-world calculation problem in C.

## Procedure

1. Start
2.	Declare variables distance, mileage, fuelprice, fuelrequired, totalfuelcost.
3.	Read distance, mileage, fuelprice
4.	Calculate the fuelrequired (distance/mileage), totalfuelcost (fuelrequired*fuelprice)
5.	Display the total fuelrequired
6.	Diplay the total fuel cost
7. Stop
