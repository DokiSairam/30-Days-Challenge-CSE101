# Challenge 01 - Student Marks Calculator

## Problem Statement

A student has marks for five subjects, write a C program to read the marks of all five subjects and to calculate the total marks, average marks and percentage. Display all three results clearly.

## Objective

To practice variables, data types, input/output statements, arithmetic operators and basic expression evaluation in C.

## Algorithm

1. Start.

2. Read the marks of five subjects.

3. Calculate the total marks.

4. Calculate the average marks.

5. Calculate the percentage.

6. Display the total, average and percentage.

7. Stop.
